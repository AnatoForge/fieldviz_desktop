# FieldViz Desktop Releases

This public repository distributes FieldViz Windows installers with cryptographically signed update manifests. The application source code is maintained in a separate private repository and is not licensed as open source by this repository.

Installers are published as GitHub Release assets. The stable update manifest is available at:

```text
https://github.com/AnatoForge/fieldviz_desktop/releases/latest/download/latest.json
```

Do not commit installers, update manifests, access tokens, or signing private keys to the Git history.
